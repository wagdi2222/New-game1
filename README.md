# معركة الدبابات 🎮

لعبة دبابات كلاسيكية على طريقة Battle City (Tank 1990)، تُلعب على جوال أندرويد.

- احمِ قاعدتك (النجمة الذهبية) ودمّر 20 دبابة معادية في كل مرحلة: 12 مرحلة مصمّمة ثم مراحل لا تنتهي
- 4 أنواع من دبابات العدو، و6 مكافآت (خوذة، ساعة، مجرفة، نجمة، قنبلة، دبابة)، وطوب وفولاذ وماء وأشجار وجليد
- صمّم خريطتك والعب عليها، وثلاث درجات صعوبة (في «سهل» لا تدمّر قذائفك قاعدتك)
- تحكم باللمس (لوحة اتجاهات وزر نار)، أو لوحة المفاتيح، أو يد التحكم؛ تعمل بالوضعين الأفقي والعمودي
- تعمل بدون إنترنت، بلا مكتبات ولا ملفات صوت خارجية

## العبها على الجوال

**من المتصفح:** https://wagdi2222.github.io/New-game1/
ثم من قائمة ⋮ في Chrome اختر «تثبيت التطبيق» لتصبح تطبيقاً بملء الشاشة يعمل بدون إنترنت.
(يحتاج الرابط تفعيل GitHub Pages مرة واحدة: Settings ← Pages ← Deploy from a branch ← `main` و `/ (root)`.)

**ملف APK:** يبنيه GitHub Actions (`.github/workflows/apk.yml`) من مجلد `android/` عند كل تحديث،
وينشره في إصدار `apk`: https://github.com/wagdi2222/New-game1/releases/download/apk/tank-battle.apk
عند التثبيت سيطلب الجوال السماح بالتثبيت من مصادر غير معروفة.

> مفتاح توقيع APK (`android/tankbattle.keystore`) منشور في المستودع حتى تُثبَّت كل نسخة جديدة فوق القديمة.
> هذا مناسب للاستخدام الشخصي؛ استخدم مفتاحاً خاصاً بك قبل النشر على Google Play.

## الملفات

| المسار | المحتوى |
|---|---|
| `index.html` | الواجهة والقوائم والتنسيق |
| `js/levels.js` | خرائط المراحل ومولّد المراحل اللانهائية |
| `js/sprites.js` | رسوم البكسل (الدبابات والأرض والمكافآت والانفجارات) مرسومة بالكود |
| `js/audio.js` | المؤثرات الصوتية المولّدة بـ Web Audio |
| `js/game.js` | محرك اللعبة: الحركة والتصادم والذكاء الاصطناعي والقذائف |
| `js/ui.js` | الشاشات والتحكم باللمس والمفاتيح ويد التحكم ومصمّم الخرائط |
| `sw.js`, `manifest.webmanifest` | التثبيت والعمل بدون إنترنت |
| `android/` | تطبيق أندرويد (WebView) يحمل اللعبة داخله |

للتجربة على الحاسوب: شغّل أي خادم ملفات ثابتة في جذر المستودع (مثل `npx http-server`) وافتح الصفحة.
